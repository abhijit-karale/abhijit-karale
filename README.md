## 🔬 About Me

Transitioning 2+ years of production embedded firmware engineering and multi-layer hardware bring-up into **RTL Design & Verification**, bringing practical hardware-software co-design intuition to verification closure. 

I specialize in **SystemVerilog, UVM, and protocol verification (AMBA-APB, AXI4-Lite)** to architect, verify, and validate digital microarchitectures. From designing and verifying 5-stage pipelined RV32I RISC-V processor cores to proving formal mathematical properties in Cadence JasperGold, I bridge the critical gap between embedded firmware, gate-level RTL, and silicon-grade verification.

- 🎓 **Education:** Final-year B.Tech in Electronics & Telecommunication Engineering (EXTC) at MAEER's MIT College of Railway Engineering & Research (MITCORER), Barshi (*Punyashlok Ahilyadevi Holkar Solapur University*), graduating in 2026 with a **CGPA of 7.86**. Prior Diploma in Railway Engineering / Electrical Engineering with distinction (**Grade 9.6 / 10**).
- ⚙️ **Engineering Trajectory:** `Embedded Systems` &rarr; `Digital Design` &rarr; `RTL & UVM Verification` &rarr; `SoC / ASIC`
- 🎯 **Current Focus:** Advanced UVM testbench architectures (virtual sequences, register abstraction layers), formal property verification (FPV) in JasperGold, and Low Power Design/Verification using Unified Power Format (UPF).

## 🚀 Featured Projects

### 1. 32-bit RISC-V Processor Design & Verification (RV32I)
*`SystemVerilog` • `UVM 1.2` • `Cadence Xcelium` • `SkyWater 130nm Flow`*
- Architected a 5-stage pipelined RV32I RISC-V processor core (Fetch, Decode, Execute, Memory, Writeback).
- Integrated dynamic hazard detection, pipeline stall logic, and full operand forwarding unit across EX and MEM stages.
- Developed a complete layered UVM 1.2 verification environment: transaction sequences, driver, monitor, memory responder agent, and scoreboard checking against Spike reference logs.
- Achieved **95%+ functional coverage closure** in Cadence Xcelium with constrained-random instruction sequences.
- 🔗 **Repository:** [abhijit-karale/riscv-soc-verification](https://github.com/abhijit-karale/riscv-soc-verification) | 🌐 **Case Study:** [Portfolio Overview](https://abhijit-karale.github.io/Portfolio/)

### 2. Memory Controller with Formal Property Verification
*`SystemVerilog` • `SVA (Assertions)` • `Cadence JasperGold FPV`*
- Designed a synthesizable single-port read/write memory controller with address range decoding and deterministic reset behavior.
- Authored comprehensive SystemVerilog Assertions (SVA) checking address boundary integrity, read-after-write dependencies, and protocol transitions.
- Achieved **100% exhaustive mathematical proofs** in JasperGold Formal Property Verification (FPV), verifying corner cases unreachable by dynamic simulation alone.

### 3. Parameterizable Asynchronous FIFO with Gray-Code CDC
*`Verilog` • `SystemVerilog` • `Clock Domain Crossing (CDC)` • `SVA`*
- Implemented a dual-clock FIFO supporting independent write and read clock domains.
- Utilized Gray-code pointer encoding and 2-flip-flop synchronizers to prevent metastability across asynchronous clock domain crossings (CDC).
- Formulated pessimistic full and empty flag generation logic to ensure data integrity; validated with protocol assertions and stress testbenches.

### 4. AMBA-APB Slave Peripheral
*`SystemVerilog` • `AMBA-APB Protocol` • `FSM Design` • `Assertions`*
- Designed an APB-compliant slave peripheral implementing the standard IDLE / SETUP / ACCESS finite state machine.
- Integrated memory-mapped configuration registers with address decode logic and error response reporting.
- Verified protocol compliance using constrained-random stimulus generation and SystemVerilog Assertions checking setup-to-enable timing.

### 5. Multi-Peripheral Industrial Firmware Engine
*`Embedded C` • `FreeRTOS` • `STM32 / ARM Cortex-M` • `Keil µVision`*
- Architected a production-grade preemptive multitasking firmware framework integrating five peripherals: **UART, SPI, I2C, ADC, and PWM**.
- Coordinated multi-sensor acquisition using FreeRTOS task queues, semaphores, and mutexes with zero task starvation and bounded interrupt latencies.
- Validated timing compliance and signal integrity on hardware using digital storage oscilloscopes and logic analyzers.

### 6. Ultra-Low-Power BLE Firmware for Edge Devices
*`Embedded C` • `Nordic nRF52840 / nRF52833` • `BLE 5.0` • `Power Profiling`*
- Engineered battery-optimized firmware implementing fine-grained System ON and System OFF sleep states.
- Configured real-time clock (RTC) triggers and peripheral state retention, substantially reducing quiescent current draw.
- Conducted laboratory power profiling to extend battery operating lifetime for remote telemetry nodes.

### 7. Industrial SCR Motor Drive Firing Package Diagnostics
*`Analog Diagnostics` • `Oscilloscope` • `Industrial Controls` • `Komatsu/Joy SCR 601849-121`*
- Isolated firing-circuit and gate-trigger failure modes in high-power industrial SCR motor drive packages.
- Correlated schematic-to-board signal paths with oscilloscope wave captures, resolving analog gate pulse degradation.
- Established a repeatable diagnostic protocol that transformed ad-hoc repair into a standardized factory testing procedure.
